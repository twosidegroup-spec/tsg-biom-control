Connect to your TSG Biom API

This dashboard reads the scan records and palm banks your phone syncs to your own TSG Biom API. Enter the API endpoint and the read key you set on the server, and choose the dashboard password that will protect them on this browser. This is a one-time setup — every later visit asks only for the password.

This browser already holds your read key from an earlier version, stored in plain text. Set your dashboard password now and the key is sealed under it — the plain-text copy is deleted, and every later visit asks only for the password.

The endpoint and key are stored only in this browser, sealed — encrypted under your dashboard password (AES-GCM, PBKDF2) — never in plain text, and sent only to your API. Disconnect clears them. Palm template contents are never displayed here. In this build the dashboard connects only to the TSG Biom API — the endpoint above is fixed for this build.
